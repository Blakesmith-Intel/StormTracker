## Active follow-up (13 October, browser freeze resolved by user)
- User confirms the original Cesium WebGL browser freeze no longer reproduces with the deployed diagnostic preview. Do not remove the three isolated GPU hover guards.
- **Issue 1: Supplemental radar clock mismatch**. The primary radar alone owns storm tracks/Doppler/3-D, but every selected additional BoM national reflectivity window must show only the exact same `observedUtc` as the *current committed primary frame*. Existing asynchronous loads could leave the prior supplementary imagery visible. The preview fix gates visibility by observation time and hides stale supplemental layers without destroying their provider until the replacement handover. Never use a nearest-time scan, inferred temporal frame, fabricated tile or stale cross-site comparison to fill the gap. New regression checks cover paused/rapid scrub/async source replacement.
- **Issue 2: Satellite imagery vanishes during pan/zoom**. The existing navigation guard set official QLD/NSW imagery `show=false` on pointer activity. The preview removes that forced visibility change and defers only local-vs-regional transition decisions while the camera moves. DEA regional and state detail providers remain active; no radar overlay is altered. Confirm responsiveness and monitor WebGL resource pressure as well as visual coverage before promotion.
- **Issue 3: 3-D omitted outside primary radar** (new user request, **not yet implemented**). `createSupplementalRadarDisplay` deliberately supports 2-D source windows only; this is a previous scientific/runtime design choice rather than a recently broken feature. Future controlled enhancement: for each source-time-matched supplemental measured reflectivity frame, build *display-only inferred* volume columns using the same BoM dBZ palette, ≥40 dBZ threshold, existing inference model, 1.0× user height exaggeration, and global volume opacity. Mask overlapping national WMTS tiles before 3-D creation, budget total GPU primitives across 1+3 sites, reuse or retire collections safely and keep labels and primary-only tracking unchanged. Never imply direct observed echo tops, invent missing pixels or generate secondary storm tracks. Must undergo separate WebGL stress and scientific-regression testing before promotion.
- Production V9.18.0 remains pinned and unchanged. The first two corrections are subject to preview tests; the third remains pending until the corrected multi-radar and imagery baseline is stable.

## Follow-up acceptance: synced secondary images + bounded 3-D (13 October)
The user confirmed the earlier preview resolved browser freezes, satellite imagery disappearing on pan, and cross-site timestamp persistence, but observed newly introduced blank/flickering supplemental imagery at each frame advance. Secondary radar regions also lacked inferred 3-D.

The preview-only fix now stages each secondary genuine BoM frame below the outgoing frame, waits for decoded Cesium readiness, and adopts all available same-UTC images *inside the primary source's beforeReveal callback*. No old secondary observation is rendered beside a newer primary observation and no old secondary is hidden while the primary still shows the previous observation. Failed/late optional windows are omitted rather than fabricated, with a bounded preparation deadline. Extra site overlap is masked at the original WMTS tile level.

Display-only inferred volumes use the existing empirical model, colourForDbzh/BoM source categories, ≥40 dBZ presentation floor, source-pixel altitude mapping, vertical exaggeration and 3-D opacity. They do not create storm tracks, threats, Doppler or measured echo tops. Sampling is limited to 250 actual strong-echo columns and 1500 Cesium glyphs per secondary site (up to three); primitive collections are reused on each frame to avoid texture destruction. Missing/disabled sites hide their volumes. Original primary tracking, alerts and 3-D science remain unchanged.

**Release gate:** tests for staging before atomic reveal, rapid next-UTC supersession, source-UTC integrity, overlap masking, volume floor/budget/opacity/collection reuse, 3-D control refresh, terrain/basemap navigation, and all existing V9.18 tests must pass. Live preview must show no flicker and no recurrence of repeated WebGL errors; production remains sealed until the user approves.
