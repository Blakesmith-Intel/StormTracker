## Accepted changes
Single permanently simplified UI. Removed expanded More options, duplicate white radar clock, obsolete diagnostic checkboxes/expanded-only controls and CSS. Preserved measured BoM reflectivity, ≥40 dBZ full-fidelity inferred 3-D, Doppler, 3 additional radar sites, tracks and cone. Sidebar fits viewport with QFD, flood, road and power controls, meaningful last-refresh timestamps and LGA customer counts. Browser map scale and geodesic measurement remain operable.

Selected additional Doppler-capable sites now display independent genuine BoM native velocity panels during Doppler-only playback with per-site source/palette, original UTC, <=8-minute clock tolerance, bounded decode/cache and immediate cancellation on mode switch. Additional sites do not generate storm IDs, official severe-weather warnings or probabilistic cyclone forecasts. Unverified NSW Doppler remains excluded.

Source-based UI and multi-Doppler regression suite passes before release. GitHub Pages root is pinned at source commit independent of subsequent main branch development.
