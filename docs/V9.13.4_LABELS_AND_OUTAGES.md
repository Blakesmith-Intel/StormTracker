# StormTracker V9.13.4 — rural labels + complete point/polygon outage coverage

## Scope and constraints
This release combines two map-layer fixes. It leaves the sealed V9.13.3
radar, Doppler, state boundary, incident panels and BoM flood-screening logic
unchanged. Operational product remains static GitHub Pages + the existing CORS
relay. No user-managed process, hosted server or local service is introduced.

## Minor Queensland place names
- Official Queensland Place Names Gazetteer, MapServer layer 1, contains
  populated places, bounded localities and suburbs (type POPL, LOCB, LOCU, SUB).
- The browser fetches these only for the geographic rectangle currently in
  view at close zoom, with padding and a bounded maximum response. No entire
  gazetteer import, periodic network polling or unrelated landform labels.
- Existing population-centre records retain priority. Duplicate nearby
  names are discarded. Older supplemental labels are removed when the
  camera moves outside the loaded extent.
- Conservative screen-space collision tests remain authoritative while
  desktop screens allow more labels at close zoom than the previous global
  five-name gate.
- Only Queensland imagery displays supplemental labels. OpenStreetMap
  Street mode continues to use its own tiles without duplicate names.
- If the gazetteer service fails, the existing town labels still display.

## Electricity outages
- Energex and Ergon publish two feature layers per distributor:
  OutageArea (0), and OutagePoint (1). V9.13.3 requested only polygons.
- Both are now fetched independently. When one layer fails, the other
  remains usable and the outage status is marked PARTIAL.
- OutagePoint incidents without a polygon are shown as red, dark-outlined
  and clickable point markers with the standard source/info panel.
- If an event is in both, prefer its polygon, with one event count and ID.
- ArcGIS pagination continues until complete, rejecting repeated pages
  and unsafe truncation. The existing 15-minute refresh interval remains.
- Planned, future and completed outages remain excluded. Essential Energy
  is still clipped to Queensland, and no NSW records are included.

## Acceptance criteria
- Mocked 8 October 2026 Ergon event 26SW12295, Brookstead, at 16:26
  Brisbane local time appears even when its provider area feed has no
  corresponding polygon; the raw current provider record may of course be
  withdrawn after restoration. No synthetic or cached persistent incident
  is shown on the real map.
- No planned incidents or duplicate point/polygon events.
- Full frontend regression workflow and official-source CORS query smoke
  must pass before production merge.
- Real browser mobile/desktop imagery/street switching verifies no
  duplicate labels, readable Birdsville and official state boundary.
- GIS source queries and source data are not altered by the app.
